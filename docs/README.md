# GitHub Pages (privacy policy)

Chrome Web Store needs a **public https URL**, not a file on your laptop.

This folder is ready to publish. After you enable Pages, the policy lives at:

`https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPO_NAME/privacy.html`

## Steps

1. Create a GitHub repository (public) and push this project.
2. On GitHub: **Settings → Pages**.
3. **Source:** Deploy from a branch.
4. **Branch:** `main` (or `master`). **Folder:** `/docs`.
5. Click **Save**. Wait 1–2 minutes.
6. Open the URL GitHub shows, then add `/privacy.html`.
7. Paste that URL into the Chrome Web Store listing under Privacy policy.

If Pages says “404”, wait a minute and hard-refresh. The site is usually `https://<user>.github.io/<repo>/`.
