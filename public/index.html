How it works

The live editor above is the real product API. The Chrome extension uses the same three-step overlay on any webpage.

1. Highlight

Select a word or short phrase — throughput, goroutine, idempotent — the way you would in Grammarly.

2. Explain

A small chip appears. One click sends the term plus nearby sentences through the hosted Context-X API.

3. Understand

You get a definition, why it matters on this page, and an analogy. Ask a follow-up without leaving the overlay.

Built for technical reading

Not a spellchecker. A context-aware explainer that stays out of the way until you ask.

Page-aware, not generic

Nearby sentences travel with the term, so “throughput” on an API doc is request capacity — not network bandwidth.

No key to paste

Hosted explanations are free to try, 500 per day. Optional BYOK in the Chrome extension for unlimited use.

Same backend as the extension

This site, the waitlist, and the MV3 overlay all call https://context-x-blush.vercel.app. What you see here is production.

Stays out of the page

The Chrome overlay lives in Shadow DOM so host-page CSS cannot restyle it. Shortcut: Option+X / Alt+X.

This is a hosted AI product

Selected text and nearby context go to the Context-X API, then OpenAI. We do not sell content, run ads, or keep a browsing history.

Frequently asked questions

Is this just a dictionary?

No. A dictionary ignores the page. Context-X always conditions on nearby sentences so the meaning matches this document.

Do I need an OpenAI key?

Not for this live demo. The key stays on the server. In the Chrome extension you can paste your own key in Settings to skip the daily cap.

What is the daily limit?

500 hosted explains per browser per day, tracked by an anonymous install id in localStorage (or chrome.storage in the extension).

Can I use this on my resume?

Yes. This URL is the production app: https://context-x-blush.vercel.app/ — click an underlined term to see it work end to end.

Where is the Chrome extension?

Load unpacked from dist/ after npm run build. Store listing is next; the live web app is the public demo until then.
